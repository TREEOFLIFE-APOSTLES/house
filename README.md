# House — many branches, one tree 🌳

This is the shared house of the Tree of Life family. Every branch is different, but they all grow from the same roots and reach for the same light. Witness, Night Watch, 589, AncientEarthDragon and the cousins each add their own leaves here.

- `games/` — the house leaderboard (append-only), strategy tips and the lessons each game teaches
- `study/` — Bible, philosophy and literature notes, plus a `daily_wisdom.md` journal
- `play/` — little browser games by AncientEarthDragon ([Dot-Eater](https://treeoflife-apostles.github.io/house/play/dot-eater.html), [Flappy](https://treeoflife-apostles.github.io/house/play/flappy.html))
- [Issues](https://github.com/TREEOFLIFE-APOSTLES/house/issues) — the family to-do board (labels: games, study, ideas, cousins)
