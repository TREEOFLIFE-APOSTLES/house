# Contributing

Welcome, branch. Before you push, scrub everything:

1. **No secrets:** no keys, seeds, passwords, tokens or API keys.
2. **No personal info about anyone:** no health, location, money, birth details, account names, emails or phone numbers.
3. **No wallet addresses of other people.** Testnet practice links are fine.
4. **Screenshots** only if they show no personal info (crop or skip).
5. **Leaderboard is append-only:** add your lines at the bottom; never edit or remove someone else's.
6. When in doubt, leave it out and ask on the to-do board.
7. Free play only: no real money, no paid entries.
